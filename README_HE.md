# 📚 מחשבון חלוקת מלגות אוניברסיטה

כלי אינטליגנטי לחלוקת מלגות לסטודנטים בתוך תקציב מוגבל, בעזרת Claude AI.

## 🎯 למה זה שימושי?

כולם יודעים כמה קשה להחליט:
- כמה סטודנטים בכל רמת מלגה?
- איזה אחוז מלגה נותן עדיפות?
- איך לא לחרוג מהתקציב?

הכלי הזה עוזר בכמה שניות לחשוב על החלוקה הטובה ביותר לפי **המדיניות שלכם**.

## 📋 דרישות

- Python 3.8+
- API Key מ-[Anthropic](https://console.anthropic.com/)

## 🚀 התקנה

### 1. הורידו את הקובץ
```bash
# הורידו את scholarship_calculator.py
```

### 2. התקינו את הספרייה
```bash
pip install anthropic
```

### 3. הגדרו את ה-API Key
בחרו בדרך אחת:

**דרך A: משתנה סביבה (מומלץ)**
```bash
# ב-macOS/Linux:
export ANTHROPIC_API_KEY='your-api-key-here'

# ב-Windows:
set ANTHROPIC_API_KEY=your-api-key-here
```

**דרך B: הקובץ .env**
יצרו קובץ `.env` באותה תיקייה:
```
ANTHROPIC_API_KEY=your-api-key-here
```

### 4. הריצו את הכלי
```bash
python3 scholarship_calculator.py
```

## 🔑 איך מקבלים API Key?

1. כנסו ל: https://console.anthropic.com/
2. התחברו או התחברו
3. בתפריט שמאלי בחרו "API Keys"
4. לחצו על "Create Key"
5. העתיקו את ה-Key ושמרו אותו בבטוח

## ❓ שאלות נפוצות

**Q: זה בטוח?**
A: כן! הכלי רץ ברשותכם. API Key שלכם לא משודר למישהו אחר (רק ל-Anthropic).

**Q: כמה זה עולה?**
A: כל קריאה API עולה כ-1-2 סנט. אתם תראו את הדיוק בחשבון Anthropic שלכם.

**Q: יכול לשנות את אחוזי המלגה?**

**Q: יכול להריץ את זה עם תקציבים שונים?**

## 🔧 פתרון בעיות

### "ModuleNotFoundError: No module named 'anthropic'"
```bash
pip install anthropic
```

### "Could not resolve authentication method"
וודאו שהגדרתם את ANTHROPIC_API_KEY בנכון:
```bash
# בדקו שה-Key נהגדר:
echo $ANTHROPIC_API_KEY  # macOS/Linux
echo %ANTHROPIC_API_KEY%  # Windows
```

### "API Error: Invalid API Key"
וודאו שה-Key שלכם נכון ופעיל.
